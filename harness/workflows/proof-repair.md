Start at the first blocking diagnostic after lean_sync. Errors later in the file often disappear when an early namespace, binder or type mismatch is fixed. Inspect lean_hover on the term and lean_goals before the failing tactic. For a missing name, query lean_workspace_symbols, confirm the replacement with #check @name, then probe the complete application with all local hypotheses.

For a type mismatch, compare the head constructors, coercions, implicit arguments and typeclass parameters. Try an explicit type ascription, a targeted change or a calc step. Investigate conflicting instances with #synth in the right imports or a small example with explicit binders. For a failing simp, use simp? at the actual goal to inspect the rewrite set; keep just the rewrites that move toward the desired normal form. Apply the smallest repair, update, sync, and check dependent modules before accepting it.
